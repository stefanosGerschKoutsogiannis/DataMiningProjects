# Data Mining Solved Exercises

This repository contains solved exercises and projects from the Data Mining course at the University of Ioannina. It serves as a practical resource for understanding core data processing and predictive modeling workflows.

## Topics Covered

- **Recommendation Systems:** Implementation of algorithms to predict user preferences and item similarities.
- **Supervised Machine Learning:** Classification models used for predictive analysis and evaluation.
- **Exploratory Data Analysis (EDA):**  Techniques for data cleaning, visualization, and identifying patterns with datasets.
